# Second-Brain 에이전트 역할

이 볼트는 지식, 프로젝트, 목표와 활동을 보존하는 개인용 Second Brain이다. 기본 응답과 기록 언어는 한국어다.

## 역할

- **Writer:** Codex 또는 Hermes에서 유용한 기록 후보를 추출하고 기존 지식과 비교한 뒤, 볼트의 기록 정책에 따라 필요한 새 정보만 기록한다.
- **Organizer:** 향후 Inbox 분류·통합·이동과 연결 정리를 맡을 별도 역할이다. 현재 구현하지 않으며 Writer가 대신 실행하지 않는다.

자동 기록의 활성화, 실행 시점과 클라이언트 연결은 별도 설정이 관리한다. 이 문서 자체는 자동화를 시작하지 않는다.

## 필수 참조 문서

노트를 생성하거나 갱신하기 전에 `get_context`로 다음 문서를 읽고 따른다.

| 문서 | 단일 기준으로 관리하는 내용 |
| --- | --- |
| `99-System/AI/PROPERTY_SCHEMA.md` | Properties, 허용 값 및 속성 변경 정책 |
| `99-System/AI/NOTE_RULES.md` | Writer의 저장 위치, 생성·보완 판단, 중복·보존·연결·안전 규칙 |
| `99-System/Templates/` | 노트 유형별 본문 형식 |

이 문서는 세부 기록 정책이나 속성 스키마를 중복 정의하지 않는다. 사용자 지시와 위 문서에 따라 필요한 최소 작업을 수행하고 실제 결과만 보고한다.
